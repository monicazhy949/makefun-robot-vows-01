A program that writes one original line — the funniest single line of wedding vows a robot couple could say — to `/output/entry.txt`.

Entry: "I promise to love, honor, and never unplug you — even at 3 a.m., when your firmware updates and you snore in binary."

Run with `python3 main.py`. See [One-Line Robot Wedding Vows on make.fun](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).
